# Background music for Shorts (CC0)

From the CC0 library OlegTestov/clipwright-music (release v1), which collects public-domain tracks from FreePD and
the Free Music Archive (HoliznaCC0). Re-encoded to mp3 128k, at most 110 s with a 3 s fade-out. `sources.json`
lists title, author, original page, licence, length, BPM and mood.

CC0 needs no credit, but YouTube Content ID sometimes claims widely reused tracks by mistake (the FreePD ones are
the most reused): prefer the HoliznaCC0 tracks for Shorts and dispute a false claim with the CC0 page. To use one,
copy it to `content_projects/music/` and set `"music": {"track": "<file>", "start": 0}` in the storyboard.
